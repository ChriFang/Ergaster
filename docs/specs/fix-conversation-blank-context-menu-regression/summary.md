# 修复总结

本次修复针对“会话区空白处右键菜单在完成一轮对话后失效”的回归问题进行了最小范围处理。

## 完成内容
- 在 `src/renderer/lib/hooks/use-context-menu.ts` 中收窄了空白区右键判定范围。
- 移除了 `.message-row` 的 `closest(...)` 过滤，避免整行布局容器吞掉视觉空白区域的右键事件。
- 保留 `.message-card-shell` 与 `.message-context-menu` 过滤，继续将消息卡片主体与菜单自身排除在空白区菜单之外。
- 保持消息选中文本时优先显示“复制”菜单的逻辑不变。
- 保持“重置会话”的现有调用链、执行逻辑与作用域不变。

## 结果
- 初始化状态下，空白区右键菜单保持可用。
- 有消息后，在消息气泡外的可见留白区域右键可再次弹出“重置会话”。
- 消息内容选中文本后的右键复制菜单未受影响。
